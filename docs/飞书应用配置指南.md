# 飞书应用配置指南

飞书知识库导出助手（Feishu Wiki Exporter）使用飞书开放平台提供的接口读取并导出知识库或云空间文件夹。第一次使用前，需要在自己的飞书企业中创建一个企业自建应用，并授予它必要的只读和导出权限。

> 通常可以在“知识空间设置 → 成员管理”中直接把企业自建应用添加为可阅读成员，不必先建立群组。错误码 `131006` 通常表示应用还没有取得知识空间资源权限。
>
> 本项目不是飞书官方产品。以下菜单名称可能随飞书开放平台更新略有变化；如果找不到某个入口，可以在开发者后台搜索对应的权限代码。

## 开始前需要知道的三层授权

应用能够导出文档，需要同时满足下面三项条件：

1. **App ID 和 App Secret 正确**：程序可以使用应用身份取得访问令牌；
2. **API 权限已经开通并生效**：应用获准调用知识库、云空间和导出接口；
3. **应用有权访问具体资源**：应用已经被加入目标知识库，或者目标文件夹已经共享给应用。

只完成其中一项或两项，仍然可能出现“连接成功但看不到知识库”或“没有权限导出”的情况。

## 一、创建企业自建应用

1. 登录[飞书开放平台](https://open.feishu.cn/)，进入开发者后台；
2. 选择**创建企业自建应用**；
3. 填写应用名称、描述和图标，例如：
   - 应用名称：`飞书知识库导出助手`；
   - 应用描述：`将本企业有权访问的飞书知识库备份到本地`；
4. 创建后进入该应用的管理页面。

不建议随意填写应用信息。清楚的名称和说明方便企业管理员审核，也方便知识库管理员在授权时确认应用身份。

## 二、添加应用能力

如飞书客户端只有在添加机器人能力后，才允许在知识空间成员中搜索到该应用，请在应用管理页面打开**添加应用能力**并添加**机器人**。

机器人不用于发送消息，只作为飞书识别和选择应用身份的能力。如果当前企业可以直接搜索并添加应用，则不需要创建群组，也不需要让机器人加入群聊。

## 三、开通最小权限

进入**权限管理**，确认选择的是**应用身份（tenant）**权限，然后搜索并开通以下五项：

| 权限代码 | 控制台中的常见名称 | 用途 |
|---|---|---|
| `wiki:wiki:readonly` | 查看知识库 | 获取知识空间和节点目录 |
| `drive:drive:readonly` | 查看、评论和下载云空间中所有文件 | 遍历云空间文件夹和下载普通附件 |
| `drive:export:readonly` | 导出云文档 | 将文档、电子表格和多维表格导出为本地文件 |
| `docx:document:readonly` | 查看新版文档 | 获取新版文档的文件块，发现内嵌附件 |
| `docs:document.media:download` | 下载云文档中的图片和附件 | 下载文件块中的 PDF 等内嵌文件 |

如果开发者后台提供**批量导入权限**，可以导入：

```json
{
  "scopes": {
    "tenant": [
      "wiki:wiki:readonly",
      "drive:drive:readonly",
      "drive:export:readonly",
      "docx:document:readonly",
      "docs:document.media:download"
    ],
    "user": []
  }
}
```

当前版本只读取和导出内容，不会创建、编辑或删除飞书文档，因此不建议开通以下写入权限：

- 编辑和管理云空间中的所有文件；
- 编辑和管理知识库；
- 编辑和管理电子表格；
- 编辑和管理多维表格。

> 这五项是按照当前程序实际调用的接口整理出的最小权限组合。后两项用于下载新版文档内嵌附件；如果不需要附件，可以在程序中取消“下载附件”，避免调用相应接口。

## 四、发布应用

权限配置完成后：

1. 进入**版本管理与发布**；
2. 创建新版本并填写版本说明；
3. 设置应用的可用范围；
4. 提交发布申请；
5. 等待企业管理员审核通过。

如果之后新增或调整了权限，通常需要重新创建版本并发布，修改才会对正式应用生效。

开发者也可以使用飞书的测试企业或测试版本进行验证，但普通用户通常不需要创建测试企业。

## 五、授权应用访问知识库

API 权限只表示应用可以调用相关接口，并不会自动赋予它读取所有企业文档的权限。还需要由知识库管理员把应用加入目标知识库。

### 整库导出推荐方法：直接添加应用

整库导出要求应用成为目标知识空间的成员或管理员：

1. 打开目标知识库的**知识空间设置 → 成员管理**；
2. 选择添加成员并搜索刚创建的企业自建应用；
3. 把应用添加为可阅读成员；
4. 重新在程序中读取知识库列表。

只做备份时不需要授予管理员权限。只有当前企业界面无法直接搜索应用时，才考虑建立专用群组、把应用机器人加入群组，再把该群组加入知识空间。

### 不要只使用“添加文档应用”

知识库管理员也可以打开文档右上角的**更多**菜单，选择**添加文档应用**，把应用添加到具体文档或节点。

但只授权单个文档或节点，不一定会使应用成为整个知识空间的成员。这种情况下，程序可能仍然无法读取知识库列表，并在手动填写知识库 ID 后返回：

```text
HTTP 400 / code 131006
permission denied: wiki space permission denied
```

因此，使用本程序导出完整知识库时，应确认应用已经出现在**知识空间设置 → 成员管理**中。

## 六、获取 App ID 和 App Secret

回到飞书开放平台的应用管理页面，打开**凭证与基础信息**，找到：

- `App ID`：通常以 `cli_` 开头；
- `App Secret`：应用密钥。

请妥善保护 App Secret：

- 不要把它写进 GitHub 仓库、脚本或公开文档；
- 不要在 Issue、聊天记录、截图或日志中公开；
- 不要使用他人提供的 App Secret，每位用户应创建自己的企业自建应用；
- 如果怀疑已经泄露，请立即在飞书开发者后台重置；
- 桌面版当前只在内存中使用 App Secret，关闭程序后不会保存。

## 七、在程序中验证配置

1. 启动**飞书知识库导出助手**；
2. 填写 App ID 和 App Secret；
3. 点击**测试连接**；
4. 点击**读取知识库列表**；
5. 选择一个只包含少量测试文档的知识库；
6. 选择导出目录和文档格式；
7. 点击**开始导出**。

需要注意：

- **测试连接**只验证 App ID 和 App Secret 是否能够取得应用访问令牌；
- **读取知识库列表**才会进一步验证知识库 API 权限和资源访问权限；
- 第一次测试建议使用小型知识库，不要直接导出企业全部资料。

## 八、导出云空间文件夹

如果要导出知识库以外的云空间文件夹：

1. 先把目标文件夹共享给应用，或者共享给包含该应用机器人的专用群组；
2. 从文件夹链接中取得 Folder Token；
3. 在程序中把**导出来源**改为**云空间文件夹**；
4. 在 **ID / Folder Token** 中填入该 Token；
5. 选择导出目录后开始导出。

如果应用只能看到文件夹但不能导出其中某些文档，请检查这些文档是否继承了文件夹权限，以及文档所有者是否限制了复制或导出。

## 九、常见问题

### 测试连接失败

优先检查：

- App ID 或 App Secret 是否复制完整；
- App Secret 是否已经重置；
- 当前网络能否访问 `open.feishu.cn`；
- 使用的是中国大陆飞书还是海外 Lark。

当前版本固定连接中国大陆飞书开放平台，暂不支持海外 Lark 的 `open.larksuite.com`。

### 测试连接成功，但知识库列表为空或读取失败

依次检查：

- `wiki:wiki:readonly` 是否已开通；
- 包含新权限的应用版本是否已发布并审核通过；
- 应用是否已经被加入目标知识库；
- 应用的可用范围是否包含当前企业成员或管理员。

如果错误代码为 `131006`，表示应用尚未成为目标知识空间的成员或管理员。请在**知识空间设置 → 成员管理**中直接添加应用；手动填写知识库 ID 不能绕过这项资源权限检查。

### 能读取知识库，但导出时报无权限

依次检查：

- `drive:export:readonly` 是否已开通并发布；
- 应用是否有权访问报错的具体文档节点；
- 文档是否来自其他知识库或外部企业；
- 文档所有者是否禁止复制或导出。

### 附件下载失败

目录中的普通附件需要 `drive:drive:readonly`。新版文档内嵌附件还需要 `docx:document:readonly` 和 `docs:document.media:download`。某些外部文件、链接卡片或单独设置过权限的附件可能需要另行授权。

### 只有少量项目失败

导出完成后查看导出目录中的 `export-report.csv`。请在反馈问题时提供错误文字和文档类型，但不要提供 App Secret 或企业内部文档内容。

## 十、最小权限验证

如果需要确认企业权限配置是否完整，可以使用只开通上述五项权限的测试应用依次验证：

- [ ] App ID 和 App Secret 可以通过“测试连接”；
- [ ] 能读取已授权的知识库列表；
- [ ] 能导出新版文档为 DOCX；
- [ ] 能导出新版文档为 PDF；
- [ ] 能导出电子表格为 XLSX；
- [ ] 能导出多维表格为 XLSX；
- [ ] 能下载 PDF、图片等普通附件；
- [ ] 能下载新版文档中作为文件块嵌入的 PDF；
- [ ] 能遍历并导出云空间文件夹；
- [ ] 无法读取未授权的知识库或文件夹；
- [ ] 第二次导出能够跳过未修改的项目。

测试完成后，如果五项权限不足，请记录失败的文档类型、接口错误代码和新增的权限名称，以便更新本指南。
